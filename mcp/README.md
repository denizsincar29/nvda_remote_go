# nvdaremote-mcp — MCP-сервер для NVDA Remote

Обёртка над библиотекой `nvda_remote_go`: даёт MCP-клиенту (Claude Desktop,
Hermes, любой другой) набор инструментов, чтобы управлять удалённой машиной
под NVDA и **читать её речь**. Речь здесь — не украшение: это единственный
источник правды о том, что произошло на той стороне.

## Сборка и запуск

```bash
go build -o nvdaremote-mcp ./cmd/nvdaremote-mcp
./nvdaremote-mcp --host 127.0.0.1 --port 6837 --channel МОЙКЛЮЧ
```

Или через переменные окружения (тогда подключение можно включить сразу):

```bash
NVDA_HOST=127.0.0.1 NVDA_PORT=6837 NVDA_CHANNEL=МОЙКЛЮЧ NVDA_AUTOCONNECT=1 ./nvdaremote-mcp
```

Сервер говорит по stdio построчным JSON-RPC 2.0 (`protocolVersion`
`2024-11-05`), в stdout не пишет ничего лишнего — логи идут в stderr.

## Подключение к клиенту

```json
{
  "mcpServers": {
    "nvda": {
      "command": "/путь/к/nvdaremote-mcp",
      "env": {
        "NVDA_HOST": "127.0.0.1",
        "NVDA_PORT": "6837",
        "NVDA_CHANNEL": "МОЙКЛЮЧ"
      }
    }
  }
}
```

## Инструменты

| Инструмент | Что делает |
|---|---|
| `connect` | Подключиться к релею как master, вернуть клиентов канала |
| `disconnect` | Закрыть соединение |
| `status` | Адрес, канал, список клиентов |
| `type_text` | Напечатать ASCII-текст с человеческим ритмом (по умолчанию 5 клавиш/с, разброс ±30%) |
| `send_keys` | Последовательность аккордов: `["control+c", "alt+tab"]` |
| `key_down` / `key_up` | Зажать/отпустить клавишу (удержания) |
| `window_list` | Обойти окна как человек: зажать Alt, жать Tab, слушать NVDA, пока имя не повторится |
| `wait_speech` | Дождаться речи NVDA и вернуть её |
| `speech_drain` | Забрать накопленную речь и очистить буфер |
| `speak` | Озвучить текст на удалённой машине |

В ответ каждого инструмента подмешивается речь NVDA, собранная за время
выполнения действия. Если NVDA молчал — так и написано.

## Ограничения

- **Только ASCII.** `type_text` не набирает кириллицу: удалённая машина может
  быть в любой раскладке, и символ всё равно уйдёт неверным. Если в строке
  встретится неподдерживаемый символ, инструмент вернёт ошибку и **ничего не
  отправит** — лучше не набрать ничего, чем половину.
- Одно активное подключение на процесс.
- `window_list` работает через переключатель Alt+Tab, поэтому на время обхода
  экран удалённой машины «дёргается». Если NVDA дважды промолчал, обход
  прекращается и возвращается то, что успели собрать.
- `jitter` — это не «обход защит» как самоцель, а способ не выглядеть идеально
  машинным потоком: одинаковые интервалы ломают часть игр и веб-форм.

## Тесты

```bash
go test ./mcp
```

Покрыто: разбор текста в клавиши (включая shift-символы и отказ на
не-ASCII), рукопожатие `initialize`, `tools/list`, ошибки `tools/call`
без подключения, ответ на неизвестный метод и отсутствие ответа на
уведомления.
